# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Static bilingual (PT default, EN under `/en/`) marketing site for mariana-marcelino.com, hosted on Vercel. Plain HTML/CSS/JS, no bundler or framework. Two kinds of pages:

- **Hand-written:** `index.html` and `en/index.html` (the homepages). Edit them directly, and keep PT and EN in sync.
- **Generated by Python:** everything else (blog, legal pages, quiz pages, 404, `sitemap.xml`, `robots.txt`, `llms.txt`, plus `api/knowledge.js` and `api/quiz-data.js`). **Don't edit generated output by hand.** Change the source script and rebuild.

## Commands

```bash
npm run dev                  # serve on http://localhost:3000 (python3 http.server)
python3 blog/_build.py       # rebuild all generated pages and files (run after any content/template change)
python3 blog/_art.py         # regenerate blog cover images in assets/blog/ (needs numpy + Pillow)
python3 guide/_build.py      # rebuild the lead-magnet guide HTML (guide/guia-pt.html, guide/guide-en.html)
python3 guide/_print.py      # print the guide to assets/*.pdf (needs site on :8765 + Chrome with --remote-debugging-port=9333)
```

There are no tests or linter.

## Build pipeline (`blog/_build.py`)

The one entry point is `blog/_build.py`. In order, it:
1. Stamps a new `?v=<timestamp>` cache-buster onto `styles.css`, `main.js` and `hero-reel.*` links in both hand-written homepages.
2. Builds the blog index and posts for PT and EN.
3. Builds the legal pages (`LEGAL` in `_build.py`, EN in `_legal_en.py`).
4. Builds the quiz pages `/diagnostico/` and `/en/diagnosis/` from `_quiz.py`.
5. Builds `404.html`, `sitemap.xml`, `robots.txt` and `llms.txt`.
6. Calls `_schema_home.py`, which rewrites the schema.org JSON-LD in both homepages from their visible content.
7. Calls `_knowledge.py`, which scrapes both homepages and blog indexes into `api/knowledge.js` for the chatbot.

So after editing homepage copy (plans, FAQ, testimonials, about), rerun the build so the structured data and the chatbot's knowledge stay in sync.

Content sources:
- Blog posts: `POSTS` in `blog/_build.py` (PT, newest first). `POSTS_EN[i]` in `blog/_posts_en.py` is the translation of `POSTS[i]`, and the index pairs them for the PT⇄EN links, so keep the order aligned.
- Legal pages: `LEGAL_EN[i]` in `_legal_en.py` is paired with `LEGAL[i]` the same way.
- Quiz: `blog/_quiz.py` is the single source of truth (questions, scoring copy, plans, report text in PT and EN). The design spec is in `docs/quiz-diagnostico.md`.
- New post covers: add a generator in `blog/_art.py`, then reference its name in the post's `cover`.

## Serverless functions (`api/`, Vercel Node)

- `api/contact.js`: receives all forms (contact, free redesign, guide, quiz report). It emails Mariana and sends the visitor a branded confirmation in the page's language through Resend. Env: `RESEND_API_KEY` (required), `MAIL_FROM`, `MAIL_TO`. Without the key it returns 503, and the front end falls back to Web3Forms.
- `api/chat.js`: the site's chat assistant, calling the Anthropic API and answering only from `api/knowledge.js`. Env: `ANTHROPIC_API_KEY`, optional `CHAT_MODEL`. It has origin allow-list and rate/length limits.
- `assets/quiz-logic.js` is a UMD-style module shared by the browser (`window.quizEvaluate`) and `api/contact.js` (`require`). The scoring logic lives there and only there.

## Gotchas

- **CSP hashes:** `vercel.json` sets a strict Content-Security-Policy. The two small inline `<script>`s in every page's `<head>` are allowed by sha256 hash. If you change either one, recompute the hash and update `vercel.json`, or that script gets silently blocked. Any new third-party script or endpoint also needs adding to the CSP.
- **Analytics:** Umami (cookieless, `cloud.umami.is`) plus Vercel Web Analytics. Custom events go through the `track()` helper in `main.js` (exposed as `window.siteTrack` for other scripts), which does nothing if Umami is blocked. If you add or remove a tracking or third-party service, update the privacy and cookie policy text in `LEGAL`/`LEGAL_EN` too.
- `.vercelignore` keeps the build scripts, `guide/`, `docs/` and `README.md` off the live site.
- Generated pages share the header, footer and `<head>` templates in `_build.py` (`head()`, `header()`, `footer()`). Changes to shared chrome go there, and also by hand in the two homepages.
- The site's writing style is plain and jargon-free, written for small-business owners. PT is European Portuguese (pt-PT).
